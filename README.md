# MAHI - AI Makeup Assistant for MAHI MAKEUP EVER

## Inspiration
I created MAHI MAKEUP EVER brand and customers always struggle to find perfect shade online. So I built an AI assistant to help.

## What it does
- User uploads selfie
- AI detects skin tone & undertone
- AI suggests perfect lipstick/foundation from MAHI collection
- User pays instantly with PayPal Checkout

## How we built it
- **PayPal Developer Platform:** Used PayPal Checkout API (Sandbox) for 1-click secure payment. Integrated PayPal Smart Buttons.
- **AI Tool:** Used AI Face Detection + Skin Tone Analysis Model as personal beauty advisor agent.

## Challenges & Accomplishments
Built first AI + PayPal integration for Pakistani beauty brand.

## Built With
- PayPal API, AI Skin Analysis, JavaScript
